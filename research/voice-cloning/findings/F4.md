## Dead ends
- No official OpenVoice Dockerfile/image from myshell-ai — only notebooks + pip package; must wrap ourselves or use community images (quality varies, many 0–4 stars).
- No evidence of gRPC endpoints for OpenVoice/XTTS/F5 community workers; the only gRPC-like path is F5-TTS's Triton+TensorRT-LLM deployment (`src/f5_tts/runtime/triton_trtllm/`), which is a heavy NVIDIA-specific stack.
- No published Redis-queue / Celery "clone+TTS job" pattern specific to OpenVoice/XTTS/F5; community workers are synchronous FastAPI or streaming HTTP. Queue integration is on us (fits AgentVoiceBox's Redis streams).
- Docker Hub `openvoice`/`xtts` search results are mostly thin repacks with no README latency claims; pull counts (57–1486) are not quality signals.
- F5-TTS official image is Gradio-demo oriented (port 7860), not a headless API worker — production API needs the FastAPI community image or custom wrapper.

## Suggested follow-ups
- Inspect `climatologist/f5-tts` Dockerfile and FastAPI routes (env vars, ports, reference-audio handling) as a template for an AgentVoiceBox F5 worker.
- Decide artifact format for multi-tenant voices: XTTS cond-latents base64 blobs vs. reference WAV + on-demand encode; store per-tenant in object storage keyed by voice_id (see F4[8]).
- If latency budget is sub-500ms TTFB, evaluate F5-TTS Triton/TRT-LLM path (253ms avg, RTF 0.0394) vs XTTS-vLLM streaming (0.45s TTFB @ c=1) on target GPU; note XTTS weights are CPML non-commercial vs F5 code MIT / weights CC-BY-NC.
- Warmup contract: health-gate workers (~50s model load) before attaching to Redis stream consumers; keep `CUDA_VISIBLE_DEVICES` pinning + `gpu_memory_utilization` caps in the worker service spec.
- For multi-tenant safety, disable prefix caching (or equivalent KV reuse across speaker embeddings) on any shared inference engine — F4[9] documents silent cross-speaker leakage.
- Prototype a thin FastAPI job wrapper (OpenAI-compatible `/v1/audio/speech`) behind the existing Channels/Redis streams, rather than adopting gRPC/Triton unless measured need.
