# F1: OpenVoice deep dive

## Findings

### [1] OpenVoice clones tone color only via a decoupled base-TTS + tone-color-converter pipeline — it does NOT clone accent, emotion, or prosody from the reference speaker.
- quote: "OpenVoice only clones the tone color of the reference speaker. It does NOT clone the accent or emotion. The accent and emotion is controlled by the base speaker TTS model, not cloned by the tone color converter"
- url: https://github.com/myshell-ai/OpenVoice/blob/main/docs/QA.md
- source_type: primary
- published: unknown (repo docs, current as of 2026-09)
- confidence: high

### [2] Official versions are V1 (arXiv Dec 2023, checkpoints_1226) and V2 (April 2024, checkpoints_v2_0417); there is no official OpenVoice V3.
- quote: "In April 2024, we released OpenVoice V2, which includes all features in V1 and has: 1. Better Audio Quality... 2. Native Multi-lingual Support... 3. Free Commercial Use."
- url: https://github.com/myshell-ai/OpenVoice
- source_type: primary
- published: unknown (README; V2 release dated April 2024)
- confidence: high

### [3] V2 natively supports English, Spanish, French, Chinese, Japanese and Korean via MeloTTS base speakers; Spanish is first-class in V2.
- quote: "Demo Usage. Please see demo_part3.ipynb for example usage of OpenVoice V2. Now it natively supports English, Spanish, French, Chinese, Japanese and Korean."
- url: https://github.com/myshell-ai/OpenVoice/blob/main/docs/USAGE.md
- source_type: primary
- published: unknown
- confidence: high

### [4] License is MIT for both V1 and V2, free for commercial use (Copyright 2024 MyShell.ai).
- quote: "OpenVoice V1 and V2 are MIT Licensed. Free for both commercial and research use."
- url: https://raw.githubusercontent.com/myshell-ai/OpenVoice/main/LICENSE
- source_type: primary
- published: 2024
- confidence: high

### [5] Checkpoints are S3 zips (not a HuggingFace weights repo for the converter): V1 `checkpoints_1226.zip`, V2 `checkpoints_v2_0417.zip` extracted into `checkpoints` / `checkpoints_v2`; V2 also requires MeloTTS + `python -m unidic download`.
- quote: "Download the checkpoint from here and extract it to the `checkpoints_v2` folder. Install MeloTTS: pip install git+https://github.com/myshell-ai/MeloTTS.git; python -m unidic download"
- url: https://github.com/myshell-ai/OpenVoice/blob/main/docs/USAGE.md
- source_type: primary
- published: unknown
- confidence: high

### [6] Worker-style integration is a small Python API: load `ToneColorConverter(config.json)`, `load_ckpt(checkpoint.pth)`, extract target embedding with `se_extractor.get_se(ref, converter, vad=True)`, then `tone_color_converter.convert(audio_src_path, src_se, tgt_se, output_path, message)`; base TTS is MeloTTS `TTS(language=...).tts_to_file(...)`.
- quote: "tone_color_converter = ToneColorConverter(f'{ckpt_converter}/config.json', device=device); tone_color_converter.load_ckpt(f'{ckpt_converter}/checkpoint.pth')... target_se, audio_name = se_extractor.get_se(reference_speaker, tone_color_converter, vad=True)"
- url: https://raw.githubusercontent.com/myshell-ai/OpenVoice/main/demo_part3.ipynb
- source_type: primary
- published: unknown
- confidence: high

### [7] Architecture is feed-forward (1D-CNN encoder → invertible normalizing flow → HiFi-GAN decoder + 2D-CNN tone-color extractor); paper reports 12× real-time on a single A10G (~85 ms per 1 s of speech), estimated upper bound ~40×; runs on CPU if CUDA is absent (`device = "cuda:0" if torch.cuda.is_available() else "cpu"`).
- quote: "a slightly optimized version of OpenVoice (including the base speaker model and the tone converter) is able achieve 12× real-time performance on a single A10G GPU, which means it only takes 85ms to generate a one second speech."
- url: https://arxiv.org/html/2312.01479v6
- source_type: primary
- published: 2023-12-03 (v1), last revised 2024-08-18 (v6)
- confidence: high

### [8] MeloTTS (required base TTS for V2) is MIT, has an official Dockerfile, covers Spanish (ES) with speaker samples, and claims CPU real-time inference — useful for AgentVoiceBox containerization.
- quote: "MeloTTS is a high-quality multi-lingual text-to-speech library by MIT and MyShell.ai. Supported languages include: ... Spanish ... Fast enough for CPU real-time inference."
- url: https://github.com/myshell-ai/MeloTTS
- source_type: primary
- published: unknown
- confidence: high

### [9] There is no official OpenVoice Dockerfile; the README points at a community Docker guide by @StevenJSCF that is now a 404 dead link, so containerization must be DIY or from community forks.
- quote: "Docker - Guide by @StevenJSCF ... You are welcome to contribute if you have a better installation guide."
- url: https://github.com/myshell-ai/OpenVoice/blob/main/docs/USAGE.md
- source_type: primary
- published: unknown
- confidence: high

### [10] Community container options exist but are thin: manzolo/myshell-openvoice-docker (41★, Ubuntu Dockerfile, last push Jul 18 2025) and ground-creative/openvoice-docker (4★, docker-compose + NVIDIA CUDA image + a Python API with OpenAI-SDK compatibility; requires NVIDIA Container Toolkit).
- quote: "Docker environment for openvoice with an api written in python. OpenAI sdk is supported... Requirements: NVIDIA gpu capable of running CUDA; NVIDIA Container Toolkit"
- url: https://github.com/ground-creative/openvoice-docker
- source_type: community
- published: unknown (67 commits; repo active as of May 2025)
- confidence: medium

### [11] Official packaging is `pip install -e .` of setup.py name `MyShell-OpenVoice` version `0.0.0` (Python >=3.9); the PyPI project `myshell-openvoice` is a quarantined 1.5 kB squat/malware placeholder from Mar 2026 and must NOT be installed.
- quote: "Quarantined — This project has been quarantined by PyPI admins... myshell-openvoice 0.1.0 ... Released: Mar 6, 2026 • Project quarantined: Mar 13, 2026"
- url: https://pypi.org/project/MyShell-OpenVoice/
- source_type: primary
- published: 2026-03-06 (PyPI squat); setup.py unpublished-to-PyPI
- confidence: high

### [12] Authors explicitly frame OpenVoice as "a Technology, not a Product" — expect imperfect clones; reference audio must be clean, single-speaker, non-trivial length, without long silence; VAD caching in `processed/` can silently reuse a stale embedding if the filename is reused.
- quote: "OpenVoice is a Technology, not a Product... The contribution of OpenVoice is a versatile instant voice cloning technical approach, not a ready-to-use perfect voice cloning product."
- url: https://github.com/myshell-ai/OpenVoice/blob/main/docs/QA.md
- source_type: primary
- published: unknown
- confidence: high

### [13] There is no official cloud inference API for self-hosters; "Quick Use" is only MyShell-hosted widgets (app.myshell.ai) and a HuggingFace Space (`myshell-ai/OpenVoiceV2`). HF Inference Providers do not deploy OpenVoiceV2. Ground-creative ships a separate OpenAI-compatible API wrapper.
- quote: "For quick use, we recommend you to try the already deployed services: [British English] ... [Spanish] ..." + "This model isn't deployed by any Inference Provider."
- url: https://huggingface.co/myshell-ai/OpenVoiceV2
- source_type: primary
- published: model updated Dec 24, 2024; Space updated Aug 2, 2024
- confidence: high

### [14] Output audio is watermarked with wavmark using `encode_message = "@MyShell"` in `tone_color_converter.convert(...)`; a production fork can clear or change this string.
- quote: "encode_message = \"@MyShell\"; tone_color_converter.convert(audio_src_path=src_path, src_se=source_se, tgt_se=target_se, output_path=save_path, message=encode_message)"
- url: https://raw.githubusercontent.com/myshell-ai/OpenVoice/main/demo_part3.ipynb
- source_type: primary
- published: unknown
- confidence: high

### [15] Repo scale/maturity signals: 37.7k stars, 4.2k forks, 287 open issues, 24 open PRs, 126 commits, no GitHub Releases/tags; setup.py pins old deps (librosa==0.9.1, faster-whisper==0.9.0, gradio==3.48.0, numpy==1.22.0) which will be painful in modern containers.
- quote: "Star 37.7k ... Fork 4.2k ... Issues 287 ... Pull requests 24 ... 126 Commits"
- url: https://github.com/myshell-ai/OpenVoice
- source_type: primary
- published: unknown
- confidence: high

### [16] Successor research (not V3): MyShell also published DreamVoice (arXiv 2406.16314, Jun 2024) — text-guided voice conversion with an OpenVoice plugin path that calls the same `ToneColorConverter` / `se_extractor` API; it is a separate model, not an OpenVoice version bump.
- quote: "DreamVoice Plugin for OpenVoice (DreamVG + OpneVoice)... openvoice = ToneColorConverter(f'{ckpt_converter}/config.json', device='cuda')"
- url: https://huggingface.co/myshell-ai/DreamVoice
- source_type: primary
- published: 2024-06-24 (arXiv); HF model updated Jan 12, 2025
- confidence: high

## Dead ends
- Official Docker guide link from USAGE.md (`github.com/StevenJSCF/OpenVoice/blob/update-docs/docs/DF_USAGE.md`) returns 404 — the branch/repo appears deleted or renamed.
- PyPI `MyShell-OpenVoice` / `myshell-openvoice` is a quarantined squat package, not a usable install channel.
- No official OpenVoice V3 release found on GitHub README, HuggingFace `myshell-ai` org, or arXiv (paper is still V1/V2-era, last revised 2024-08-18); `MeloTTS-English-v3` on HF is a MeloTTS base-speaker checkpoint, not OpenVoice V3.
- Exact minimum reference-audio duration is never quantified in official docs (QA only says "Is your audio too short?").
- No fetched source gives Spanish-specific MOS/quality numbers — Spanish support is claimed as native in V2 but quality is undocumented quantitatively.

## Suggested follow-ups
- Pin down practical reference-clip length and Spanish quality by running V2 (`checkpoints_v2_0417.zip` + MeloTTS-ES) against AgentVoiceBox test utterances on CPU and one GPU.
- Evaluate `ground-creative/openvoice-docker` + `openvoice-api-python` (OpenAI-compatible) as a worker-sidecar template vs writing our own thin FastAPI wrapper around `ToneColorConverter`.
- Inventory dependency-pin breakage (librosa 0.9.1 / numpy 1.22 / gradio 3.48 / faster-whisper 0.9.0) and whether MeloTTS's official Dockerfile can carry the converter load without the OpenVoice notebook stack.
