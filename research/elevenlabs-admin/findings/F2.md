# F2: ElevenLabs UX modules and IA

## Findings

### [1] Voice settings are five named controls: Speed, Stability, Similarity, Style exaggeration (aka style), and Speaker Boost; defaults ~50 stability / ~75 similarity / 0 style
- quote: "The most common setting is stability around 50, similarity around 75, and keeping style at 0, with minimal changes thereafter. ... The speed setting allows you to either speed up or slow down the speed of the generated speech. The default value is 1.0 ... a minimum of 0.7 ... a maximum of 1.2."
- url: https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech
- source_type: primary
- published: unknown
- confidence: high

### [2] Per-model gating of voice controls matters for OSS admin: Speed and Similarity and Speaker Boost are not available for Eleven v3; Style exaggeration is off-by-default and costs latency
- quote: "Speed is not available for the Eleven v3 model. ... Similarity is not available for the Eleven v3 model. ... Speaker Boost is not available for the Eleven v3 model. ... In general, we recommend keeping this setting at 0 at all times."
- url: https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech
- source_type: primary
- published: unknown
- confidence: high

### [3] Model selection is productized as use-case cards (Quality / Low-latency / Expressive realtime / Multilingual / Balanced + Content creation / Agents Platform / Voice changer) with character limits and language counts
- quote: "For guidance on which model best fits your requirements and use case, see the model selection guide. ... Requirements: Quality ... Low-latency ... Expressive realtime ... Multilingual ... Balanced ... Use case: Content creation ... Agents Platform ... Voice changer"
- url: https://elevenlabs.io/docs/overview/models
- source_type: primary
- published: unknown
- confidence: high

### [4] Voice Library / My Voices cards expose language, category, notice period, quality tier, and type icons; actions are "More actions" (three dots): Copy voice ID, Edit voice, Share voice, View history, Delete voice; Collections + Shift+Click multi-select
- quote: "You will see the following information about each voice: the language it was trained on. the category, for example, \"Narration\". how long the notice period is, if the voice has one. ... Click More actions (three dots) to: Copy voice ID ... Edit voice ... Share voice ... View history ... Delete voice"
- url: https://elevenlabs.io/docs/eleven-creative/voices/voice-library
- source_type: primary
- published: unknown
- confidence: high

### [5] Marketplace filters are the IA pattern for voice discovery: Language, Accent, Category (Conversational, Narration, Characters, Social Media, Educational, Advertisement, Entertainment), Gender, Age, Notice period, Live Moderation, Quality; entry path is sidebar "Voices" → "Explore"
- quote: "To access the Voice Library, click Voices in the sidebar and select Explore. ... Use filters to refine your search: Language ... Accent ... Category ... Gender ... Age ... Notice period ... Live Moderation enabled ... Quality"
- url: https://elevenlabs.io/docs/eleven-creative/voices/voice-library
- source_type: primary
- published: unknown
- confidence: high

### [6] Sidebar IA: "Text to Speech" is a sidebar entry with a History tab in the right panel (download MP3/WAV/Advanced formats); related docs place Voices, Studio, Dubbing, and a bottom-of-sidebar "Developers" area in the same left nav
- quote: "log in to your account and select Text to Speech in the sidebar, then access your history by clicking the history tab in the panel on the right side of the screen."
- url: https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech
- source_type: primary
- published: unknown
- confidence: medium

### [7] Studio projects layer long-form IA on top of TTS: Project settings (Model, Advanced normalization, Export metadata Title/Author/ISBN), Chapters sidebar, per-paragraph Voice + Override settings + Generation history + Lock paragraph, Insert break (max 3s), multi-voice per paragraph with color orbs
- quote: "Enable Override settings to change voice settings for the selected text or paragraph. ... Select Lock paragraph to prevent changes to a paragraph. ... You can add a pause by using the Insert break button. ... By default, this will be set to 1 second, but you can change the length of the break up to a maximum of 3 seconds."
- url: https://elevenlabs.io/docs/eleven-creative/products/studio
- source_type: primary
- published: unknown
- confidence: high

### [8] Pronunciation dictionaries are project-scoped and opened via a "Pronunciations Editor"; rules are alias tags or phoneme tags (IPA/CMU); dictionaries are connected with a "Connect" dropdown; phoneme tags are model-limited
- quote: "Pronunciations opens the Pronunciations Editor, where you can add alias or phoneme rules. ... Existing pronunciation dictionaries can be connected to your project from the Pronunciations Editor. ... Phoneme tags are only compatible with \"Eleven Flash v2\" model."
- url: https://elevenlabs.io/docs/eleven-creative/products/studio
- source_type: primary
- published: unknown
- confidence: high

### [9] SSML is partial, not full: `<break time="1.5s" />` and phoneme tags on older models; Eleven v3 replaces SSML with Audio Tags (`[whispers]`, `[laughs]`, `[sad]`) and explicitly does not support SSML break tags
- quote: "With Eleven v3, use audio tags and punctuation to control pacing and delivery. Eleven v3 does not support SSML break tags. ... The most consistent way to add a pause on Multilingual v2, Flash v2, and Flash v2.5 is with the SSML break tag syntax <break time=\"1.5s\" />."
- url: https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech
- source_type: primary
- published: unknown
- confidence: high

### [10] Dubbing Studio UI (legacy, maintenance mode) is the timeline+speaker-card pattern: Speaker Cards (transcribe/translate/edit), Timeline with Split/Merge/reassign, Track vs Clip voice settings with "inherit track settings" toggle, Dynamic vs Fixed Generations, "Generate Stale Audio", Clip History; exports AAC/MP3/WAV/AAF/SRT/CSV
- quote: "You can set voice settings at two levels: 1. Track Level ... 2. Clip Level ... Disable the 'inherit track settings' toggle and configure your desired settings. ... you can regenerate stale clips individually or click 'Generate Stale Audio' to bulk generate all stale audio clips."
- url: https://elevenlabs.io/docs/eleven-creative/products/dubbing/dubbing-studio
- source_type: primary
- published: unknown
- confidence: high

### [11] Agent voice tools taxonomy for an AgentVoiceBox admin: Client Tools, Webhook tools, Code Tools, MCP Tools, System Tools; plus Tool Call Sounds and Tool Interruptions toggles
- quote: "ElevenLabs Agents supports the following kinds of tools: Client Tools ... Webhook tools ... Code Tools ... MCP Tools ... System Tools. ... Tool Call Sounds ... Tool Interruptions"
- url: https://elevenlabs.io/docs/eleven-agents/customization/tools
- source_type: primary
- published: unknown
- confidence: high

### [12] Multilingual behavior is text-driven, not a language picker: language comes from input text, accent comes from the voice; website auto-detects, API adds optional `language_code`; no in-app language selector
- quote: "When you generate audio on the ElevenLabs website, our AI automatically detects the language based on the context of the text of your prompt. ... At the moment, it isn't possible to specify a language when generating on the website. ... The language is determined by the text, while the accent and pronunciation are determined by the voice itself."
- url: https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech
- source_type: primary
- published: unknown
- confidence: high
